MP4/ISO-BMFF ftyp brand detection samples (all videos on one page)

Repro page for the multi-video rendering issue: every sample is embedded here. Isolated single-video pages are linked from mp4_brand_tests.html.

One file per major/compatible brand, generated with ffmpeg. Used to verify mmmagic/wi_magic detection (see WI-44553 and the follow-up brand-coverage ticket).

Already covered by unplayable.mp4 at the repo root (compatible brands: iso4/hvc1/isom) - not duplicated here.

cmfc

Video-only (no audio), H.264 (libx264), major and compatible brand both cmfc. Earlier versions copied the same defective HEVC bitstream as unplayable.mp4 (the original WI-44553 file) - with no audio track to anchor the media pipeline, that bitstream defect made the whole load abort after ~1s instead of just blanking the video like iso5-8 (which have audio) do. Re-encoded from a clean H.264 source to decouple this from the unrelated HEVC bug.

Download cmfc.mp4

cmfs

Video-only (no audio), same as cmfc above but with the cmfs brand forced instead.

Download cmfs.mp4

av01

Real AV1 encode (libaom-av1) - ffmpeg tags the av01 compatible brand automatically.

Download av01.mp4

hev1

Brand forced via ffmpeg's -brand override; underlying stream is the same HEVC content as unplayable.mp4.

Download hev1.mp4

avc3

Real H.264 encode (libx264) with in-band parameter sets; brand forced via -brand override.

Download avc3.mp4

vp09

Real VP9 encode (libvpx-vp9); brand forced via -brand override (ffmpeg doesn't tag it automatically).

Download vp09.mp4

vp08

Not included - ffmpeg's mp4 muxer refuses to mux VP8 into an mp4 container at all ("codec not currently supported in container"). No real-world sample could be produced.
