MP4/ISO-BMFF ftyp brand detection samples

One file per major/compatible brand, generated with ffmpeg. Used to verify mmmagic/wi_magic detection (see WI-44553 and the follow-up brand-coverage ticket).

Each brand is on its own isolated page - putting many <video> elements on one page was found to trigger a separate, unrelated WI video-rendering issue (confirmed: the exact same file plays fine in isolation but not when many other videos share the page), so this index intentionally avoids embedding any <video> tags directly.

cmfc

Video-only (no audio), H.264 (libx264), major and compatible brand both cmfc. Re-encoded from a clean H.264 source rather than copying unplayable.mp4's HEVC stream - see cmfc_v2's note below for why.

cmfc_v2

Same content as cmfc - kept as a second copy from an earlier investigation into whether copying unplayable.mp4's HEVC stream (which has the illegal in-band parameter-set repeat from WI-44553) without an audio track to anchor the media pipeline caused playback to abort after ~1s instead of just blanking the video like iso5-8 (which have audio) do. Confirmed via fireglass.log; both cmfc and cmfc_v2 are now re-encoded with clean H.264 to decouple this from the unrelated HEVC bug.

cmfs

Video-only (no audio), H.264 (libx264), major brand cmfs. Re-encoded from a clean H.264 source for the same reason as cmfc - see cmfc_v2's note below.

av01

Real AV1 encode (libaom-av1) - ffmpeg tags the av01 compatible brand automatically.

hev1

Brand forced via ffmpeg's -brand override; underlying stream is the same HEVC content as unplayable.mp4 (has audio, so the WI-44553 defect should only blank the video, not abort the whole load).

avc3

Real H.264 encode (libx264) with in-band parameter sets; brand forced via -brand override.

vp09

Real VP9 encode (libvpx-vp9); brand forced via -brand override (ffmpeg doesn't tag it automatically).

vp08

Not included - ffmpeg's mp4 muxer refuses to mux VP8 into an mp4 container at all ("codec not currently supported in container"). No real-world sample could be produced.
