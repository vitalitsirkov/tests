MP4 ftyp brand samples - H.264 versions

Every file is H.264 + AAC (640x360, 10 s) with the brand forced as the major brand, so the picture decodes on any browser (no HEVC/AV1/VP9 decoder needed). The tests only care about the ftyp header, not the codec. msdh and msix (DASH segments) are not playable and are not included.
